# FlackyFixer

Ассистент для анализа и исправления нестабильных автоматизированных тестов с использованием больших языковых моделей.

### Возможности:

- загрузка и обработка отчётов JUnit XML;
- отображение результатов выполнения тестов;
- автоматическое извлечение stacktrace;
- поиск и отображение исходного кода теста;
- генерация рекомендаций с использованием LLM;
- поддержка OpenAI API и совместимых интерфейсов;
- возможность использования локальных моделей;
- хранение истории анализа;
- развёртывание через Docker.

### Запуск через Docker

```docker compose up --build``` из корня репозитория

### Конфигурация:

## Конфигурация

Проект использует файл `.env` для настройки интеграций и параметров окружения.

### Переменные окружения

| Переменная | Обязательная | Описание | Пример |
|---|---|---|---|
| `OPENAI_API_KEY` | Да | API-ключ для доступа к языковой модели | `sk-...` |
| `LLM_PROVIDER` | Да | Провайдер языковой модели | `openai` или `local` |
| `GITHUB_TOKEN` | Нет | Токен GitHub API для доступа к репозиторию | `ghp_xxx` |
| `GITHUB_OWNER` | Да | Владелец репозитория с тестами | `AlexFaernon` |
| `GITHUB_REPO` | Да | Название репозитория | `flackyfixer` |
| `POSTGRES_URL` | Да | Строка подключения к PostgreSQL | `postgresql://admin:admin@db:5432/flackyfixer` |
| `VITE_API_URL` | Да | URL backend API для frontend | `http://localhost:8000` |
